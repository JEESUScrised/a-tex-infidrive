A-Tex InfiDrive

Экспериментальный сервис: произвольный файл кодируется в MP4, при необходимости загружается на YouTube через официальный Data API, а затем может быть восстановлен из полученного видеофайла.

Перейти в приложение

Как это работает

Данные укладываются в яркостные блоки кадров по формату InfiDrive/YTDrive v1, упаковываются в H.264 через FFmpeg и при желании публикуются как private-видео через Google OAuth и YouTube Data API v3. Восстановление выполняется по MP4, который вы сами скачиваете (например, из YouTube Studio) и импортируете обратно.

Неофициальное скачивание роликов с YouTube не используется и не поддерживается.

Важные ограничения

  • Сервис экспериментальный и не предназначен для критичных архивов.
  • Бессрочное или гарантированное хранение файлов на YouTube не обещается.
  • YouTube может сжимать, ограничивать или удалять ролики по своим правилам.
  • Доступ к приложению закрыт: режим single-admin без публичной регистрации.
