A-Tex InfiDrive
Главная Условия Приложение

Политика конфиденциальности

Версия для ограниченного тестового развёртывания. Реквизиты оператора — к заполнению.

1. Оператор

Сервис A-Tex InfiDrive предоставляется A-Tex Group. Полные юридические реквизиты оператора, адрес и контакты для запросов субъектов данных будут указаны после предоставления соответствующих сведений.

2. Какие данные обрабатываются

  • Учётные данные администратора (логин и хеш пароля на стороне сервера).
  • Загружаемые файлы, производные MP4, метаданные заданий и контрольные суммы SHA-256.
  • При подключении YouTube — OAuth-токены Google, идентификатор и название канала, video ID и статусы загрузки.
  • Технические журналы сервера (без секретов и токенов в открытом виде).

3. Google / YouTube

Подключение YouTube выполняется только авторизованным администратором через официальный OAuth 2.0 и YouTube Data API v3. Используются минимально необходимые scope (youtube.upload, youtube.readonly). Токены хранятся в зашифрованном виде. Сервис стремится соблюдать Google API Services User Data Policy, включая требования Limited Use.

Данные, полученные из Google API, не продаются и не используются для рекламы. Отключение аккаунта YouTube удаляет сохранённые OAuth-токены на стороне сервиса.

4. Цели обработки

Обеспечение работы закрытого административного приложения: кодирование/декодирование файлов, фоновые задания, опциональная загрузка на YouTube и восстановление из MP4.

5. Хранение и безопасность

Данные хранятся на сервере приложения (SQLite и файловое хранилище). Доступ к API защищён сессией администратора. Публичная регистрация пользователей отсутствует.

6. Передача третьим лицам

При явном действии администратора файл (как видео) может быть загружен в Google/YouTube. Иные передачи персональных данных третьим лицам не предполагаются, кроме случаев, требуемых законом.
