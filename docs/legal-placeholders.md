# Юридические данные для заполнения

Страницы `/privacy` и `/terms` намеренно не содержат выдуманных реквизитов.

Укажите перед публичным запуском:

1. Полное юридическое наименование оператора (A-Tex Group / юрлицо).
2. ОГРН / ИНН (или аналог для юрисдикции).
3. Юридический и почтовый адрес.
4. Email для запросов субъектов персональных данных.
5. Email / адрес для претензий по условиям использования.
6. Ответственное лицо / DPO (если применимо).
7. Юрисдикция и применимое право.
8. Политика сроков хранения загруженных файлов и логов.
9. Порядок удаления аккаунта YouTube и локальных данных по запросу.

До подтверждения этих данных в публичных текстах используется пометка «к заполнению».
